# tomheo-relatable

AI 티 안 나는 글과 디자인을 위한 규칙 스킬입니다.

관례적인 라벨을 걷어내고 문장 부호를 사람이 쓰는 방식으로 맞추고 익숙한 문체로 쓰게 합니다.


## 설치

```
/plugin marketplace add tom-heo-biik/tomheo-relatable
/plugin install tomheo-relatable@tomheo-relatable
```


## 사용

사용자에게 보여줄 글을 쓰거나 퇴고할 때 그리고 화면이나 문서를 디자인할 때 자동으로 불립니다. 직접 부르려면 아래와 같이 합니다.

```
/tomheo-relatable:tomheo-relatable
```


## 구성

| 스킬 | 내용 |
| --- | --- |
| `tomheo-relatable` | 라벨 걷어내기, 문장 부호 규칙, 사람 냄새 나는 문체 |
